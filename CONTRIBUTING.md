# Contributing to RiSPICE

Thank you for your interest in contributing to RiSPICE!

## Reporting Issues

If you encounter a bug, unexpected behavior, or other technical issue, please open an issue in the [GitHub repository](https://github.com/bioinfodlsu/rispice/issues).

When reporting an issue, please include:
- A clear description of the problem.
- Steps to reproduce the issue, if applicable.
- Relevant error messages or logs.
- Your environment details, such as the operating system and RiSPICE version.

Please avoid including sensitive information in issue reports.

## Suggesting Improvements

Suggestions for new features, improvements, or documentation are welcome. Please open a GitHub issue describing your proposal and its intended use.

## Contributing Code or Documentation

Contributions to the codebase and documentation are welcome.

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them where applicable.
4. Submit a pull request describing your changes and their purpose.

Please keep contributions focused and consistent with the existing project structure and coding style.

## Seeking Support

For questions about installation, usage, or configuration, please check the [README](README.md), the [project wiki](https://github.com/bioinfodlsu/rispice/wiki), and existing [GitHub issues](https://github.com/bioinfodlsu/rispice/issues) first. If your question remains unanswered, open a GitHub issue with sufficient context to help clarify your concern.

Thank you for helping improve RiSPICE!
