# Getting Started

This guide walks through the complete RiSPICE workflow using the **OsHAK1 promoter** case study presented in the manuscript. Starting from a VCF containing promoter variants, you will reproduce the prediction, analysis, and mutagenesis workflow used in the study.

## Prerequisites

Before beginning, complete the following steps from the [wiki](https://github.com/bioinfodlsu/rispice/wiki/1.-Installation):

- Install RiSPICE.
- Download the RiSPICE model and target adapter.
- Download the empirical background distribution.

## Expected Directory Structure

This tutorial assumes the following working directories:

```text
.models/
.data/
.analysis/
.figures/
```

| Directory | Purpose |
|-----------|---------|
| `.models/` | Downloaded RiSPICE base model and LoRA adapter. |
| `.data/` | Intermediate outputs generated by the prediction pipeline. |
| `.analysis/` | Analysis results derived from the pipeline outputs. |
| `.figures/` | Generated figures and visualizations. |

> These directory names are only recommendations. You are free to organize your project differently provided the paths in the commands are updated accordingly.

## Example Dataset

The example dataset is located at:

```text
getting-started/data/hak1.vcf.gz
```

This compressed VCF contains variants from the **2 kb promoter region of OsHAK1** extracted from the SNP-Seek 18M SNP dataset.

## Walkthrough

Follow the tutorials in order:

1. **Run the Pipeline** (`Run-the-Pipeline.md`)
   - Convert the example VCF into a `snp_list.tsv`.
   - Generate reference and alternate sequences.
   - Predict chromatin feature probabilities.
   - Compute the Per-Feature and Overall Scores.

2. **Analyze the Results** (`Analyze-Results.md`)
   - Rank variants by Overall Score.
   - Analyze and visualize Per-Feature Scores.
   - Identify the top candidate variant for further investigation.

3. **Mutagenesis** (`Mutagenesis.md`)
   - Perform in silico saturation mutagenesis around the selected variant.
   - Annotate statistically significant mutations.
   - Generate the mutation heatmap and maximum effect line plot.

Each walkthrough provides the exact commands needed to reproduce the OsHAK1 case study.
